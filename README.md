# Hamdallah Alhassan — Portfolio

A responsive React and Vite portfolio prototype for Hamdallah Alhassan, highlighting selected GitHub projects, animation work, community impact, leadership, education, certificates, and technical interests.

## Run locally

```bash
npm install
npm run dev
```

Vite prints a local URL after the development server starts.

## Production build

```bash
npm run build
npm run preview
```

## Portfolio content

Project entries, project-detail content, experience, education, certificates, skills, and community initiatives are maintained as structured data in `src/App.jsx`. The project browser can be filtered by field, and each card opens a detailed view. Cards also link directly to each available GitHub repository, live demos, and supplied report PDFs.

The project browser groups work under AI & machine learning, data & BI, networks, product & web, and creative & animation. The related creditworthiness repositories and repeated Local Store link are consolidated into single entries. PCC Finance and the signup application are based on the supplied brief and marked for review because a matching repository was not confirmed in the public GitHub account. Video animation is included as creative work; the linked animation repositories have no source files yet, so project specifics and samples remain to be added.

## Personal assets and editable items

- Replace `public/images/hamdallah.webp` to update the profile portrait.
- Replace the project and community images in `public/images/` to update supplied screenshots and photographs.
- Replace `public/Hamdallah-Alhassan-CV.pdf` to update the downloadable CV.
- The Google Data Analytics certificate PDF and verification link are displayed in the certificate section. Add certificate images and credential links to the certificate entries in `src/App.jsx`.
- Supplied Sales Trends and Social Media Analysis report PDFs are in `public/reports/` and are linked from their project cards.
- Update project links, dates marked “to confirm,” contact details, and certificate links before publishing.
- Project and community photographs use supplied local images where available and remote Unsplash images elsewhere; replace stock images with approved project photography as it becomes available.
- The contact and call-request form validates fields in the browser only. It does not send messages or reserve meetings; connect an email service or booking service before enabling delivery.
- Google Fonts and the stock photographs require an internet connection.
